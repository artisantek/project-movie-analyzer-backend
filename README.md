# Project Movie Analyzer - Backend

This repository contains the backend microservice for the Movie Analyzer application, built with Spring Boot and PostgreSQL. It handles API requests, database interactions, and interfaces with the sentiment analysis model.

## Infrastructure & CI/CD
* This service includes its own `Jenkinsfile` for CI/CD.
* Kubernetes deployment configurations can be found in the `helm/` directory.

> **Note:** For general infrastructure setup, database configuration scripts, and overall architecture instructions, please refer to the main repository: [movie-analyzer-project](https://github.com/artisantek/movie-analyzer-project).
